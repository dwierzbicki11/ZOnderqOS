## Goal

Add the smallest real per-CPU scheduler foundation after the scheduler policy
and its `PerCpuState` array have been initialized. This stage does not claim a
full SMP scheduler, managed AP idle threads, thread migration, context
switching on APs, or preemption.

## Implementation

- Adds a one-shot atomic Stage-13 phase and entry counter to every
  `PerCpuState`.
- Adds a managed C# reverse-P/Invoke entry that runs on each AP, verifies its
  dense `CpuId`, the matching idle/current thread and scheduler policy state,
  performs `enter -> leave`, publishes the phase/count, and returns.
- Adds a native command-6 mailbox and fixed-IPI wake path. After the managed
  proof, each AP returns to the existing native HLT loop.
- Adds BSP validation for every AP's native completion, managed phase/count,
  command clearing and ninth IPI acknowledgement.
- Adds a Stage-13 serial checker and a 1-vCPU plus 8-vCPU GitHub Actions
  workflow. The Stage-12 QEMU/stability contract is reused as a regression
  gate.
