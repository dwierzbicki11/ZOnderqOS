# SMT Stage 8 — parked AP native command wake

Base main: `1228f839b0c0ee76345a33783f9d63e137120cf8` after the Stage 7 merge.

Stage 8 adds a native-only parked command proof. BSP publishes one command to every AP, sends a fixed IPI, and each AP executes the command after returning from the interrupt to its native `hlt` parking loop. The command increments the existing native AP work counter from `100000` to `100001`, reports completion, and leaves the AP parked again.

This proves the AP can wake from the parked path, acknowledge the interrupt, return from the handler, execute bounded native idle-loop work, and park again. It does not run managed runtime, GC, or the scheduler on APs.
