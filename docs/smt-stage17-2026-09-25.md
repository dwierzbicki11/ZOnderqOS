# SMT Stage 17 — AP-local timer preemption and context resume

Stage 17 starts from the Stage 16 head
`d5ccd7643609182241d1a2ba35d0ca17de666227`. Stage 16 proved one genuine
managed `SchedulerThread` dispatch per application processor and a clean
timer-driven return to the enrolled per-CPU idle context on QEMU
`1S/4C/2T`.

## Runtime proof

For every AP, Stage 17 must prove this complete sequence:

1. enqueue a pinned managed worker in that CPU's existing Stride run queue;
2. enter it through the common F4 IRQ/context-switch path;
3. arm the AP-local LAPIC timer from the running worker;
4. preempt the still-runnable worker through vector EF;
5. restore the enrolled native idle IRQ context;
6. dispatch the same worker again and resume its saved timer-interrupt context;
7. let the worker publish a deterministic checksum, exit, and return to idle;
8. leave no runnable Stage 17 worker or armed proof timer behind.

The preemption and resume counters must be owned by `PerCpuState`. Native
mailboxes may coordinate the proof, but must not replace scheduler state or
manufacture PASS markers.

## Implementation constraints

- Reuse the existing per-CPU scheduler state, Stride run queue, common IRQ
  stubs and `ScheduleFromInterrupt`; do not jump directly between worker and
  idle stacks.
- Keep the Stage 16 one-shot proof intact as a regression.
- Keep workers pinned for this stage. Migration and load balancing follow
  only after timer preemption and saved-context resume are stable.
- Keep AP timer and command state cache-line-local or per-CPU. Avoid global
  mutable proof state in interrupt paths.
- ARM64 remains compile-only until its MP bootstrap and IRQ-return context
  switch exist; do not claim ARM64 SMP runtime.

## Required gates

- patch apply, reverse-check and idempotence against Cosmos v3.0.85;
- clean patched Cosmos package build and local-feed verification;
- x64 ISO build;
- QEMU Nehalem 1-vCPU regression;
- QEMU Nehalem `1S/4C/2T` runtime with one complete preempt/resume/exit proof
  for each of the seven APs and a stability interval;
- all Stage 0–16 serial regressions;
- ARM64 managed compile regression.
